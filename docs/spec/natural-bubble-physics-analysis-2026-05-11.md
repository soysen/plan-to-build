# 需求分析：自然泡泡物理（Spring-Physics + Canvas）

## 1. 目標
不使用重量級物理引擎（如 Matter.js），而是透過 **自定義彈簧物理 (Spring Physics)** 與 **Canvas 渲染**，實現具備「水面波紋感」與「彈性互動」的泡泡系統。

## 2. 核心特徵定義
- **彈性斥力 (Spring Repulsion)**：泡泡間的推擠基於彈簧受力（Hooke's Law），碰撞時會有平滑的緩衝與回彈，而不是剛體碰撞。
- **水感阻尼 (Fluid Damping)**：模擬水中的摩擦力，讓泡泡的移動具備慣性且能平穩停止，避免無窮震盪。
- **彈性邊緣 (Wobbly Edges)**：泡泡在受力時半徑會產生微小的彈性縮放，模擬果凍般的質感。
- **畫布渲染 (Canvas Rendering)**：配合 SVG Gooey Filter 實現邊緣融合的視覺效果。

## 3. 技術方案選型
| 方案 | 特點 | 理由 |
| --- | --- | --- |
| **自定義彈簧物理** | 極輕量 (數百行內)、高度可控 | 符合「水面波紋/彈簧」的感官需求，避開 Matter.js 的生硬感。 |
| **Canvas 2D API** | 高效能 | 適合大量點位的即時計算與繪製。 |
| **SVG Gooey Filter** | 視覺強化 | 提供流體般的邊緣黏合效果。 |

## 4. 範疇 (Scope)
- **IN**: 實作 `SpringPhysicsEngine` 處理位置與受力計算。
- **IN**: 使用 Canvas 繪製具備漸層與動態半徑的泡泡。
- **IN**: 滑鼠互動改為「施加推力」而非硬性的坐標綁定。
- **OUT**: 複雜的剛體旋轉、複雜的形狀碰撞（僅處理圓形）。
