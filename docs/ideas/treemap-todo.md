## 問題陳述

我們如何讓一個人打開 Chrome 的瞬間，不需要思考，就直覺知道今天哪件事最重、哪件最緊，進而決定從哪裡開始？

---

## 視覺方向決策記錄

評估了三種有機造型方案後，選定 **B — Blob 泡泡** 作為 MVP 視覺方向：

| 方案 | 描述 | 決定 |
|------|------|------|
| A — Voronoi 細胞圖 | 完全填滿視窗，最大化比例精確度 | 暫緩（複雜度高） |
| **B — Blob 泡泡** ★ | **有機造型漂浮在深色背景，大小∝重要度** | **選定** |
| C — 有機邊框矩形 | 保留格子結構，圓角處理 | 不選（有機感表面） |

**已知 tradeoff**：Blob 不填滿視窗，背景有空隙；重要度的比例感靠大小體現，不如 Treemap 精確。使用者已知悉並接受。

## Value Proposition

> 為了需要同時管理多個輕重緩急任務的工作者，在每次打開 Chrome 的時刻，Treemap Todo 提供視覺化的任務全局圖，不像一般 Todo 列表要靠大腦自己排序，我們讓**重要度決定視覺份量、deadline 決定顏色緊迫感**。

---

## 使用者背景

- **對象**：個人使用（自己），未來可能擴展
- **情境**：每次打開 Chrome 看到（New Tab 替換，長期目標）
- **現況痛點**：任務靠腦袋＋Azure Planner 管理，無法一眼看到全局輕重
- **核心需求**：直觀、簡單操作，不需要學習成本

---

## 推薦方向

### MVP — Blob 泡泡視覺化

有機 blob 造型漂浮在深色背景上，重要度（1–5）決定 blob 大小，deadline 決定顏色（綠→黃→橘→紅），做成單一 `index.html` 先跑起來用。

**視覺語言**：
- 背景：深色（`#0a0a0f` 或深藍黑）
- Blob：使用 CSS `border-radius` 多值或 SVG path 製造不規則有機感
- 大小：重要度 1 = 小 blob，重要度 5 = 大 blob（面積比約 1:4）
- 顏色：距 deadline > 7 天 = 冷綠，3–7 天 = 黃，1–3 天 = 橘，< 1 天 = 紅
- 動畫：blob 輕微漂浮（CSS keyframe，緩慢晃動感）

### V2 — 子任務 + 交互精緻化

點擊 blob 進入子任務視圖（同樣的 blob 風格），加入展開/收合動畫。

### V3 — Chrome Extension

包裝成 Chrome Extension，替換 New Tab 頁面，成為每天開 Chrome 的入口畫面。

---

## MVP 範圍（In Scope）

- 新增 / 編輯 / 刪除任務
- 設定重要度（1–5）→ 決定 blob 大小
- 設定 deadline → blob 顏色從綠漸變紅（越近越紅）
- 層級：1 層子任務（任務 → 子任務，點擊 blob 展開）
- `localStorage` 持久化
- 視窗 resize 自動重新排列 blob 位置
- Blob 輕微漂浮動畫（提升生命感）

---

## 不做（及原因）

- **Treemap / Voronoi（填滿視窗）** — 使用者選擇 Blob 風格，接受背景有空隙的 tradeoff
- **跨設備同步** — MVP 不需要，增加複雜度，localStorage 先夠用
- **AI 自動判斷重要度** — 使用者明確要自己設定
- **Azure / 外部系統整合** — V2 以後的事
- **Chrome Extension 打包** — MVP 先驗證 UI 夠不夠好用，確認有用才包裝

## 需要驗證的核心假設

- [ ] localStorage 不跨裝置在初期可以接受
