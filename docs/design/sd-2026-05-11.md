# SD: 彈簧泡泡物理系統設計 (System Design)

## 1. 技術設計核心：Spring Physics
每個泡泡 (Blob) 具備以下屬性：
- `pos`: 向量 (x, y)
- `vel`: 向量 (vx, vy)
- `acc`: 向量 (ax, ay)
- `radius`: 基礎半徑
- `spring`: 彈力係數 (Stiffness)
- `damping`: 阻尼係數 (Friction)

### 物理演算法
1. **斥力計算**：當 `dist(b1, b2) < (r1 + r2)` 時：
   - `overlap = (r1 + r2) - dist`
   - `force = overlap * stiffness`
   - `b1.acc -= force_vector`, `b2.acc += force_vector`
2. **邊界反彈**：碰撞邊緣時施加反向力。
3. **隨機漂浮**：`acc += (Math.random() - 0.5) * strength`

## 2. 渲染設計 (Canvas)
- 使用 `requestAnimationFrame` 進行渲染。
- **Gooey 濾鏡**：
  ```css
  #blob-canvas {
    filter: url('#goo'); /* 指向 SVG 濾鏡定義 */
  }
  ```
- **泡泡繪製**：
  - `ctx.beginPath()`, `ctx.arc()`
  - 使用 `RadialGradient` 增加 3D 球體感。
  - 根據速度 (velocity) 進行輕微的橢圓形變 (Scaling)。

## 3. 文字處理 (DOM Overlay)
為了讓文字排版與互動（如點擊按鈕）最穩定，建議採用 **DOM Overlay** 方案：
- Canvas 只畫泡泡背景。
- 文字標籤與按鈕使用透明的 DOM 元素，每一幀根據物理座標同步 `transform: translate(x, y)`。

## 4. 關鍵參數 (待調校)
- `STIFFNESS`: 0.05 - 0.2 (決定推擠有多硬)
- `DAMPING`: 0.9 - 0.98 (決定停下的速度)
- `DRIFT_STRENGTH`: 0.01 (隨機漂浮強度)
