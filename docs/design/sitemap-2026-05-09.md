## 頁面結構圖

這是一個**單頁應用（SPA）**，無路由切換，以「視圖狀態」區分畫面。

```mermaid
graph TD
    Root["🌐 index.html\n（應用入口）"]

    Root --> MainView["📋 主視圖\nMai Blob Canvas\n（所有頂層任務）"]
    Root --> EmptyState["⬜ 空狀態\n無任務時的引導畫面"]

    MainView --> AddModal["➕ 新增任務 Modal\n（overlay 覆蓋主視圖）"]
    MainView --> EditModal["✏️ 編輯任務 Modal\n（overlay 覆蓋主視圖）"]
    MainView --> SubtaskView["📂 子任務視圖\n（替換主視圖，有 breadcrumb）"]
    MainView --> DeleteConfirm["🗑️ 刪除確認提示\n（inline 或 toast）"]

    SubtaskView --> AddSubModal["➕ 新增子任務 Modal"]
    SubtaskView --> EditSubModal["✏️ 編輯子任務 Modal"]
    SubtaskView --> BackNav["⬅️ Breadcrumb 返回主視圖"]

    EmptyState --> AddModal
```

---

## 視圖狀態說明

| 視圖 ID | 名稱 | 觸發條件 | 主要功能 |
| ------- | ---- | -------- | -------- |
| VIEW-001 | 主視圖（Main Blob Canvas） | 預設 / 無任務以外情況 | 顯示所有頂層任務 blob |
| VIEW-002 | 空狀態（Empty State） | `tasks.length === 0` | 引導使用者新增第一個任務 |
| VIEW-003 | 子任務視圖（Subtask View） | 點擊有子任務的 blob | 顯示該任務的子任務 blob |
| OVERLAY-001 | 新增任務 Modal | 點擊「＋」按鈕 | 輸入名稱、重要度、deadline |
| OVERLAY-002 | 編輯任務 Modal | 長按 / 右鍵 blob | 修改任務資料 |
| OVERLAY-003 | 刪除確認 | 編輯 Modal 點刪除 | 二次確認防誤刪 |

## 使用者動線圖

```mermaid
graph LR
    Start([打開頁面]) --> CheckTasks{有任務?}
    CheckTasks -- 否 --> EmptyState[空狀態畫面]
    CheckTasks -- 是 --> Main[主視圖 Blob Canvas]

    EmptyState -- 點擊新增 --> AddModal[新增 Modal]
    Main -- 點擊 ＋ --> AddModal
    AddModal -- 確認送出 --> Main
    AddModal -- 取消 --> Main

    Main -- 長按 blob --> EditModal[編輯 Modal]
    EditModal -- 儲存 --> Main
    EditModal -- 刪除 --> DeleteConfirm[刪除確認]
    DeleteConfirm -- 確認 --> Main
    DeleteConfirm -- 取消 --> EditModal

    Main -- 點擊 blob\n有子任務 --> SubtaskView[子任務視圖]
    SubtaskView -- breadcrumb --> Main
    SubtaskView -- 點擊 ＋ --> AddSubModal[新增子任務 Modal]
    AddSubModal -- 確認 --> SubtaskView

    Main -- 點擊完成按鈕 --> Main
```
