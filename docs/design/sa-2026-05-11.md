# SA: 彈簧泡泡物理系統分析 (System Analysis)

## 1. 系統架構圖
```mermaid
graph TD
    User([使用者]) <--> IH[MOD-004: InteractionHandler]
    IH -- 施加衝量/力 --> PE[MOD-002: SpringEngine]
    TaskStore[(MOD-001: TaskStore)] -- 同步數據 --> PE
    PE -- 更新位置與縮放 --> RE[MOD-003: CanvasRenderer]
    RE -- 繪製每一幀 --> Canvas([Canvas 畫面])
```

## 2. 功能模組切分

| 模組 ID | 名稱 | 職責 |
| --- | --- | --- |
| MOD-001 | TaskStore | 負責任務資料持久化。 |
| MOD-002 | SpringEngine | 核心物理迴圈。計算 Spring Force、Damping 與 Brownian Drift。 |
| MOD-003 | CanvasRenderer | 高頻渲染。處理畫布清除、泡泡路徑繪製與 Gooey Filter 應用。 |
| MOD-004 | InteractionHandler | 將滑鼠移動轉化為物理場中的力或速度改变量。 |

## 3. 使用者流程圖 (彈性推擠)
```mermaid
sequenceDiagram
    participant U as 使用者
    participant IH as MOD-004
    participant PE as MOD-002
    participant RE as MOD-003

    U->>IH: 滑鼠靠近/拖拽
    IH->>PE: 向泡泡施加力 (Force)
    loop 每一幀 (requestAnimationFrame)
        PE->>PE: 計算重疊彈力: F = -k * x
        PE->>PE: 計算阻尼: F_d = -c * v
        PE->>PE: 更新 v = v + a, p = p + v
        PE->>RE: 傳遞新坐標與變形量 (Scale/Wobble)
        RE->>RE: Canvas 渲染
    end
```
