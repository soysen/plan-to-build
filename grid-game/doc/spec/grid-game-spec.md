# 規格書 (Specification)

## 專案名稱：康威生命遊戲 (Conway's Game of Life)

- **版本**：v1.0
- **狀態**：草稿
- **作者**：AI Agent (Antigravity) & User

---

## 1. 產品概述
本專案為瀏覽器端的「康威生命遊戲」模擬器，使用 React 與 TypeScript 開發。目標是提供一個兼具**高水準視覺設計 (Aesthetics)**、**極致渲染效能 (Performance)** 以及**完整測試保護 (TDD)** 的網格遊戲範例，並在此過程中完整驗證 `plan-to-build` 的 AI 協作工作流。

---

## 2. 核心遊戲邏輯 (生命演化規則)
遊戲網格由二維細胞 (Cell) 組成，每個細胞有兩種狀態：**存活 (Alive)** 或 **死亡 (Dead)**。在每一次的時間 Tick（世代更迭）中，細胞的下一階段狀態由周圍 8 個鄰居細胞的存活數量決定：

1. **孤單死亡 (Underpopulation)**：若一個存活的細胞，其存活鄰居數**少於 2 個**，該細胞死亡。
2. **穩定生存 (Survival)**：若一個存活的細胞，其存活鄰居數為 **2 個或 3 個**，該細胞在下一世代繼續存活。
3. **過擠死亡 (Overpopulation)**：若一個存活的細胞，其存活鄰居數**多於 3 個**，該細胞死亡。
4. **繁衍復活 (Reproduction)**：若一個死亡的細胞，其存活鄰居數**剛好為 3 個**，該細胞在下一世代復活。

### 邊界處理規則 (Toroidal Grid / Wrap-around)
為避免生命在邊界斷絕，網格採用**繞回 (Wrap-around / 環面棋盤)** 機制：
- 第一列細胞的「上方鄰居」為最後一列的對應細胞。
- 第一欄細胞的「左方鄰居」為最後一欄的對應細胞。
- 其他邊界以此類推。

---

## 3. 功能需求

### 3.1 網格與繪圖互動 (Grid & Draw)
- **網格維度**：預設為 30 x 30 的細胞矩陣。
- **單擊切換 (Click to Toggle)**：點擊任何細胞可切換其狀態（死 ➔ 活，活 ➔ 死）。
- **拖曳繪製 (Drag to Draw)**：按住滑鼠左鍵並在網格上滑動，可將滑過的所有細胞設為存活狀態 (Alive)，方便使用者繪製大型圖案（如 Glider 噴射器）。

### 3.2 控制面板 (Control Panel)
- **開始 / 暫停 (Start / Pause)**：控制遊戲是否自動依時間間隔演化。
- **下一世代 (Next Step)**：在暫停狀態下，手動前進一格 Tick。
- **清空 (Clear)**：停止演化，並將網格上所有細胞重置為死亡狀態。
- **隨機生成 (Randomize)**：以隨機初始密度（預設為 30% 存活率）重新分佈所有細胞。
- **速度調整 (Speed Slider)**：調整時間 Tick 的間隔，範圍自 100ms（極速）至 1000ms（慢速）。

---

## 4. 非功能需求與品質要求 (DoD)

### 4.1 視覺與介面設計 (Aesthetics)
- **配色計畫**：
  - 背景：深邃太空格調色 (`#0B0F19` 或 `#070A13`)。
  - 存活細胞：亮青色/霓虹綠 (`#10B981` 到 `#06B6D4` 的漸層)，且具備微弱的發光特效 (Neon Glow)。
  - 死亡細胞：微透的暗灰藍 (`rgba(255, 255, 255, 0.03)`)。
- **磨砂玻璃 (Glassmorphism)**：控制面板使用磨砂玻璃質感 (`backdrop-filter: blur(12px)`)，搭配細緻的微光邊框 (`border: 1px solid rgba(255,255,255,0.08)`)。
- **微互動 (Micro-animations)**：
  - 細胞生死轉移時，需有縮放 (`scale(0.8) ➔ scale(1)`) 與顏色漸變效果，且時長在 150ms 內，保持流暢敏捷。
  - 按鈕懸停 (Hover) 與點擊 (Active) 有明確的陰影與光澤反饋。

### 4.2 效能指標 (Performance)
- **渲染優化**：
  - **核心限制**：在 Tick 更新時，只有狀態發生變化的細胞元件 (Cell) 可以觸發 React Re-render。
  - **幀率要求**：演化動畫在一般電腦上必須保持 **60 FPS**。單次計算與重繪之 JS 執行時間必須小於 16ms。

### 4.3 測試覆蓋率
- 遊戲核心演化運算子 (`src/core/gameEngine.ts`) 必須編寫 100% 的單元測試。整體邏輯測試覆蓋率必須大於 **90%**。
